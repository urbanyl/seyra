# Seyra

Зашифрованные сессии чата. Один код, без аккаунта, ничего не остаётся.

Сайт: [seyra.website](https://seyra.website)

**Другие языки:** [English](README.md) · [Français](README.fr.md) · [中文](README.zh.md) · [한국어](README.ko.md)

## Что делает

- Код — это ключ. PBKDF2-HMAC-SHA256 (210 000 итераций) даёт 32 байта ключа и 32 байта идентификатора комнаты.
- Сообщения запечатываются XSalsa20-Poly1305 до отправки из браузера. Идентификатор автора тоже запечатан.
- Текст, голосовые, фото, файлы до 8 МБ, опросы, ветки, закреплённые сообщения, упоминания.
- Групповые звонки, камера и демонстрация экрана со звуком, напрямую через WebRTC.
- Всё живёт в оперативной памяти. Закрыл сессию — у всех всё стёрлось.

## Чего не делает

- Нет forward secrecy и нет PAKE. Идентификатор комнаты работает как офлайн-проверка кода.
- Нет выравнивания размеров, поэтому размеры сообщений утекают.
- Нет восстановления. Потерял код — потерял сессию.
- Внешнего аудита пока нет.

Полное техническое досье с цифрами и моделью угроз: [/securite](https://seyra.website/securite).

## Запуск

Нужен Node 20+.

```sh
cd app && npm install && npm run build   # клиент собирается в server/public
cd ../server && npm install
node src/index.js                        # 127.0.0.1:3000
```

Впереди nginx с TLS (см. `deploy/nginx-seyra.conf`). Переменные: `PORT`, `ALLOWED_ORIGINS`, `TURN_HOST`, `TURN_SECRET`.

TURN-релей опционален, но помогает в строгих сетях (`deploy/setup-turn.sh`).

## Структура

```
app/      клиент React + Vite
server/   сервер Node WebSocket, отдаёт собранный клиент
deploy/   конфиг nginx, unit systemd, установка coturn
```
